# PANDU.DEV — Premium Animated Developer Portfolio

**PANDU.DEV** is a high-performance, animated developer portfolio for **I. Jayasaisrinandhan**, B.Tech Computer Science Engineering Student at KL University.

## 🚀 Key Highlights & Architectural Features

- **Brand & Visuals**: Dark premium aesthetic (`#090a0f`), glassmorphism, responsive clamp typography (`Syne` + `Plus Jakarta Sans`), ambient glowing accents, and subtle particle canvas.
- **Intro / Loading Screen**: GSAP-animated loading sequence revealing `PANDU.DEV` and `Design • Code • Create` before sliding up into the hero.
- **Hero Section**: Fullscreen hero with large background parallax typography `PANDU`, status badge, dual CTAs, and ambient glow.
- **About Me**: Professional student profile card featuring credentials, role, location, and educational aspirations.
- **Education (Academic Journey)**: Animated timeline for B.Tech CSE at KL University with slots for future milestones.
- **Technical Skills**: Authentic skill cards (C, Java, Python basics, HTML, CSS, Data Structures, Problem Solving, Git, GitHub, MS Office) with realistic badges — **strictly zero fake percentage bars**.
- **Currently Learning**: Interactive cards for Java & OOP, Data Structures & Algorithms, Web Development, AI & Machine Learning, and Git & GitHub.
- **Interests**: Lucide-icon cards covering Programming, Web Development, AI, Machine Learning, UI/UX Design, and Exploring Tech.
- **Strengths (What Defines Me)**: Quick Learner, Hardworking, Team Player, Problem Solver.
- **Editorial Career Goal**: Signature scroll-scrub highlighting inspired by high-end editorial experiences, lighting up each word dynamically as you scroll.
- **Projects (Things I Build)**: Structured placeholder cards clearly marked `Coming Soon` with technology tags and repository/demo hooks.
- **GitHub & Code Experiments**: Clean repository cards with language indicators and zero fake metrics.
- **Contact & Let's Connect**: Form validation with clear notice regarding backend integration and instant mailto client fallback.
- **Secure Profile Editor**: Built-in PIN-authenticated (`pandu2026`) modal for live profile configuration, instant preview, discard/cancel, and persistent storage.
- **Animations & Performance**: Lenis smooth scrolling synchronized with GSAP ScrollTrigger, respecting `prefers-reduced-motion`.

---

## 🛠️ Tech Stack

- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, PostCSS, Custom Glassmorphism
- **Motion & Scrolling**: GSAP 3, ScrollTrigger, Lenis
- **Icons**: Lucide React
- **State & Storage**: React Context API + LocalStorage persistence
